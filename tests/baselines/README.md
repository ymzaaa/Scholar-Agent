# 端到端结构化基准

本目录只保存经过人工审核、可公开的合成 JSON 期望。真实论文基准、模板编译 PDF、完整日志和历史验收证据在私有测试环境中维护，不随仓库分发。

`synthetic/` 保存由 `tests/support/build_word_cases.py` 构造的完全合成 Word 案例预期。`feedback/` 保存合成用户反馈的预期决策。预期描述目标产品行为，不根据当前程序输出自动反写；当前实现与目标不一致时应记录为待实现差异。

运行方式：

```powershell
python -m pytest -q
```

完整端到端测试始终使用 pytest 临时目录。测试完成后不得把临时生成目录复制回本目录。
